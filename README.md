# Esport Platform: backend

REST API for the esports leagues and tournaments platform. A team project built at Collegium Witelona.

Related repositories:

- project documentation and Figma: https://github.com/Mallinowo/esport-platform
- frontend: https://github.com/Mallinowo/Esport-frontend

## Scope

- registration and login by email or with Discord
- teams, invitations, roles (user, captain, organizer, administrator)
- round-robin leagues and knockout tournaments, team registration
- schedule and bracket generation on the server
- result reporting and confirmation, dispute handling
- league table and win/loss record updated automatically
- live result updates over WebSocket
- admin panel and application logs

## Tech stack

- Laravel (REST API)
- Sanctum, Socialite (Discord)
- Reverb (WebSocket)
- Scramble (OpenAPI documentation)
- Spatie Activitylog
- PostgreSQL
- PHPUnit
- Docker Compose, GitHub Actions

## Running locally

Requirements: Docker and Docker Compose.

```bash
git clone https://github.com/Mallinowo/Esport-backend.git
cd Esport-backend
cp .env.example .env
docker compose up -d
docker compose exec app composer install
docker compose exec app php artisan key:generate
docker compose exec app php artisan migrate --seed
```

The API is available at http://localhost:8000/api.

## API documentation

The OpenAPI specification is generated by Scramble and available at http://localhost:8000/docs/api. The frontend uses it to generate API types and the client.

## Tests

```bash
docker compose exec app php artisan test
```
